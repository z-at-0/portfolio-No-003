# portfolio-No-003: Personal Portfolio Site

## 概要

自身の制作実績を一覧化し、外部へ提示するためのポートフォリオサイトです。 閲覧者が直感的に情報を得られるよう、シンプルかつ見やすいレイアウトを心がけています。

## 主な機能

- トップページでの直感的なナビゲーション
- 各コンテンツへのリンク・詳細ページへの遷移
- モーダルウィンドウでの拡大表示（必要に応じて）
- レスポンシブデザイン: PC・タブレット・スマホへの最適化

## 使用技術

使用言語: HTML5, CSS3, JavaScript (Vanilla JS)
技術要素: CSS Flexbox / Grid によるレイアウト構築
メディアクエリを用いたレスポンシブ対応
ライブラリ: なし（標準技術のみで構築）

## 学習・AI活用について

本プロジェクトは2021年に制作されたものであり、AIツール等は一切使用していません。

## 補足

004〜006ではAIを効率的な学習ツールとして取り入れていますが、この003はそれ以前に「自力でゼロから形にする力」を身につけるために制作したものです。この時期に培った基礎があるからこそ、現在のプロジェクトにおいてAIの提案内容を正しく精査し、主体的に扱うことができています。
